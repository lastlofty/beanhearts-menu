# Beanhearts — концепт современного онлайн-меню

Демонстрационный проект адаптивного сайта-меню для ресторана Beanhearts.

## Возможности

- адаптивный интерфейс для компьютеров и смартфонов;
- поиск по блюдам и ингредиентам;
- категории и фильтры;
- карточки с фотографиями, составом, весом и калорийностью.
